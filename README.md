# Biryani Dwar

The official website for **Biryani Dwar**, an authentic chicken biryani restaurant in Harnaut, Bihar. Fragrant basmati, carefully blended spices and generous portions from ₹80.

**Live:** [www.biryanidwar.com](https://www.biryanidwar.com)

## Features

- **Hero**: animated intro with headline, starting price and quick actions
- **Menu**: biryani options, plus a **Build your plate** panel of add-ons with prices
- **Why Biryani Dwar**: what sets the food apart
- **Our story**: the restaurant's background
- **Reviews**: what customers say
- **Visit us**: address, opening hours (daily 12 PM – 9 PM), an embedded Google Map and directions
- **Order**: one-tap **call** and **WhatsApp** ordering
- **Instagram** link and a mobile menu
- Smooth **GSAP** scroll animations that switch off for users who prefer reduced motion
- SEO and Open Graph metadata for rich link previews

## Tech Stack

| | |
|---|---|
| Build tool | Vite |
| Language | Vanilla JavaScript, HTML, CSS |
| Animation | GSAP + ScrollTrigger |
| Fonts | Cormorant Garamond, Great Vibes, Outfit (Google Fonts) |

## Project Structure

```

src/
├── main.js       # All sections, content, links and animations
├── style.css     # Styles
└── assets/       # Images
public/           # Favicon and static files
```

## Getting Started

```bash
git clone https://github.com/Anjalisinggh/dwar-biryani.git
cd dwar-biryani
npm install
npm run dev
```

Open the local URL Vite prints (usually [http://localhost:5173](http://localhost:5173)).

`npm run build` creates a production build in `dist/`, and `npm run preview` serves it.
